## Cross-Interview Synthesis

### Finding #1: Cashflow is the Connecting Tissue

**Appears in all 20 interviews**:
- **IC interviews**: "I don't know when money's arriving"
- **TC interviews**: "I don't know my tax liability"
- **Both**: "Can't make confident business decisions"

**Implication**: Don't optimize invoicing or tax in isolation. Build unified cashflow dashboard.

### Finding #2: Emotion Matters More Than Features

**Strong in 8+ interviews**:
- Solopreneurs have psychological barriers (shame, anxiety, intimidation)
- They need automation + simplicity + professional appearance
- One new feature < one less stress point

### Finding #3: Segmentation Is Critical

**Clear across all 20**:
- **Solopreneurs**: Need simplicity + automation + education
- **Agencies**: Need visibility + integration + team features
- **Founders**: Need optimization + forecasting + strategic guidance
- **Commission-based**: Need flexibility + dynamic estimates
- **Seasonal**: Need custom handling

One-size-fits-all fails. Build core + differentiate by segment.

### Finding #4: Three Jobs Connect Everything

1. **Get Paid** (IC focus) → Cashflow visibility
2. **File Taxes** (TC focus) → Tax liability visibility
3. **Make Decisions** (both) → Unified cashflow + tax view

All three trace back to same root need: **financial clarity for confident decision-making**.

### Finding #5: Integration > Consolidation (Nuance)

- **Full consolidation** (own everything) = high switching cost, limited adoption
- **Best-of-breed** (many tools) = fragmentation, admin burden
- **Hub model** (integrate with existing tools) = sweet spot
  - Ledger as hub (invoicing + payments + cashflow + taxes)
  - Deep integrations with Stripe, QB, bank feeds, etc.
  - Don't try to own every layer
